# Product Backlog

## Historias de usuario

### 1. Autenticación
- **Como** captador **quiero** registrarme con email, contraseña, nombre y RUT **para** acceder al sistema.
- **Como** captador **quiero** iniciar sesión **para** obtener un token de acceso.

### 2. Gestión de prospectos
- **Como** captador **quiero** crear un prospecto con RUT y nombre **para** registrar un interesado.
- **Como** captador **quiero** que el sistema valide RUT duplicado **para** evitar registros repetidos.
- **Como** captador **quiero** listar prospectos paginados **para** revisar los registros.

### 3. Documentación
- **Como** equipo **quiero** documentar el modelo de datos **para** mantener el sistema.
- **Como** equipo **quiero** tener un manual técnico **para** facilitar instalación.

## Prioridad
1. Autenticación (alta)
2. Crear prospecto (alta)
3. Listar prospectos (media)
4. Documentación (media)
